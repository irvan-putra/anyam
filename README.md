# Human-AI shared context: a proposal

This repository holds a proposal for turning the human-AI task division and "shared cognitive layer" dynamic into a software system or research project. It sketches two tracks:

- **Option A - a software/product angle:** a "context-first" collaborative orchestration layer that captures human tacit knowledge as structured input before AI execution, maps conflicting assumptions across stakeholders, and routes AI output to the right human reviewers.
- **Option B - a research angle:** formalizing human-AI collaborative governance and tacit knowledge elicitation, including study designs that compare team topologies and routing of adversarial human review.

## Contents

- `proposal-gemini.md` - the original proposal text, preserved verbatim as written by Gemini (Google's model) in a chat conversation.
- `framing-and-limitations.md` - notes on how to read the proposal: what it is, what it is not, and what has not been validated.

## Status

This is an idea-stage document. Publishing it here does not select either track, and there is no implementation, benchmark, or study behind it yet. See `framing-and-limitations.md` before citing or building on it.
